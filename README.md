# Project X — پیش‌نمایش محصول

یک تجربه‌ی اجتماعی و موبایل‌محور برای ساخت دورهمی، دعوت دوستان و بازی‌کردن با چالش‌های کوتاه.

## مشاهده و اجرا

این مخزن کد پیش‌نمایش رابط کاربری Project X است. برای اجرای محلی به Node.js 20 یا جدیدتر نیاز دارید:

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## جهت طراحی

- مینیمال، ظریف و قابل‌اعتماد؛ با فضای سفید و جزئیات کنترل‌شده
- تایپوگرافی فارسی خوانا و چیدمان کامل راست‌به‌چپ
- رنگ‌های خنثی با تأکید سبز ملایم
- اولویت موبایل، سلسله‌مراتب بصری روشن و تعامل‌های ساده
- پرهیز از ادعای قابلیت‌هایی که هنوز ساخته نشده‌اند

## وضعیت واقعی نسخه

در این پیش‌نمایش می‌توانید نوع بازی را انتخاب کنید، اتاق آزمایشی بسازید، بازیکن نمونه اضافه کنید و جریان چند سؤال تا صفحه نتیجه را روی همان دستگاه ببینید.

**هنوز فعال نیست:** دعوت چنددستگاهی و لینک عضویت واقعی، حساب کاربری، پایگاه داده، همگام‌سازی زنده، ذخیره دائمی نتایج و تولید محتوای هوش مصنوعی. این مخزن یک نمونه‌ی رابط و تجربه است، نه سرویس آماده انتشار عمومی.
